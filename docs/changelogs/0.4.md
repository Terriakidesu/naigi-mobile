# 0.4.x

> **Beta.** Naigi mobile remains an unfinished preview.

## 0.4.4 — 2026-10-09

### Changed

- Bundles frontend 0.5.4: polished focused-video header and controls, participant names instead of voice UUIDs, portrait-aware viewing, and redesigned camera tiles/dock. Still **Naigi Beta**. Phone media validation remains pending; no installation was performed.

## 0.4.3 — 2026-10-09

### Fixed

- Bundles frontend 0.5.3: front/back switching restarts one camera publication instead of trying to run both cameras at once. Includes facing-mode switching, recovery attempts, and cancellation guards. Still **Naigi Beta**; physical phone validation remains pending.

## 0.4.2 — 2026-10-09

### Fixed

- Bundles frontend 0.5.2: capture already-subscribed streams on joining, keep controls within narrow screens, and reserve dock space instead of overlapping tiles. Still **Naigi Beta**. Real phone media validation remains pending.

## 0.4.1 — 2026-10-09

### Changed

- Bundles frontend 0.5.1 with themed custom camera/device and stream-quality menus instead of OS dropdowns. Touch targets, selected states, and keyboard accessibility remain available. Still **Naigi Beta**.

## 0.4.0 — 2026-10-09

### Added

- Bundles shared frontend 0.5.0: independent camera/screen resolution and FPS settings, camera selection, and touch-expand viewing with fit/fill and supported fullscreen.
- Shared-audio controls and remote share volume where screen capture is supported.

### Fixed

- Simultaneous camera/share previews, tile rebuilding, cancelled capture, and stream cleanup.

### Limitations

- Android native screen sharing remains unavailable. Camera/device and two-client encrypted playback validation is still pending; no phone installation was performed for this release.
