# 0.4.x

> **Beta.** Naigi mobile remains an unfinished preview.

## 0.4.0 — 2026-10-09

### Added

- Bundles shared frontend 0.5.0: independent camera/screen resolution and FPS settings, camera selection, and touch-expand viewing with fit/fill and supported fullscreen.
- Shared-audio controls and remote share volume where screen capture is supported.

### Fixed

- Simultaneous camera/share previews, tile rebuilding, cancelled capture, and stream cleanup.

### Limitations

- Android native screen sharing remains unavailable. Camera/device and two-client encrypted playback validation is still pending; no phone installation was performed for this release.
