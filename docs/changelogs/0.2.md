## 0.2.0 — 2026-10-08

Updates the bundled interface to `naigi-frontend` 0.3.0. The app still installs as **Naigi Beta** and is still a preview.

### Added

- Adult-content warnings and spoiler rooms, in the phone drawer and on every other client. A room marked as adult content shows a warning and loads nothing until you continue, and marked rooms carry a mark in the drawer so the warning is visible before opening one. A spoiler room conceals message bodies, quoted replies, media behind the existing blurred previews, file names, and decrypted text-file previews until each is revealed.
- Both markers are set per room from Space settings → Rooms, and are asked for only by members who manage rooms.

### Changed

- The bundled interface version query strings follow the app version, so an update cannot run cached scripts from a previous build.
